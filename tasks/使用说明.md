# 股指期货净空单量分析程序使用说明

## 快速开始

### 1. 手动运行
```bash
python tasks/futures_net_short_position_analyzer.py
```

### 2. 测试程序
```bash
python tasks/test_futures_analyzer.py
```

### 3. 定时任务
程序已集成到任务调度器中，每天下午5点自动执行。

## 功能特点

✅ **自动下载数据**: 从中金所官网自动下载四个股指期货（IH、IF、IM、IC）的持仓数据

✅ **智能解析**: 自动识别中信证券和其他券商的持仓情况

✅ **统计分析**: 计算净空单量变动和总持仓情况

✅ **策略建议**: 根据净空单量提供做多/做空建议

✅ **微信推送**: 自动发送分析报告到微信

✅ **容错处理**: 支持多种编码格式，网络异常时使用模拟数据

## 报告示例

```
2025年08月05号，净空单数据如下：
某信，IF加空69手, IH减空132手, IC减空440手, IM减空1402手；
其他主要玩家，IF加空595手, IH加空1389手, IC减空1166手, IM减空3682手；
合计对IH、IF加空1921手，合计对IC、IM减空6690手。
连续三天偏向中小盘股。
操作完成后，共持有净空单85855手。
净空单量在正常范围内，建议观望。
```

## 策略规则

- **净空单量 < 6.5万**: 适合做多
- **净空单量 > 11万**: 适合做空  
- **6.5万 ≤ 净空单量 ≤ 11万**: 建议观望

## 注意事项

1. 数据一般在当天收盘后才有，程序会在下午5点前使用昨天的数据
2. 需要稳定的网络连接来下载数据
3. 微信发送功能需要Windows系统并安装微信客户端
4. 程序会自动处理编码问题，确保数据正确解析
