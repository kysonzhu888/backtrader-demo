# 布林线策略回测程序

## 简介

这是一个基于 Backtrader 框架的布林线策略回测程序，用于测试布林线交易策略在历史数据上的表现。

## 策略说明

### 核心逻辑
- 使用布林线突破策略（**以收线为准**）
- **做多信号**：K线收盘价突破上轨时做多，收盘价回撤到中轨时平仓
- **做空信号**：K线收盘价突破下轨时做空，收盘价回升到中轨时平仓
- **重要**：所有开平仓信号都需要等待K线收盘确认，避免假突破
- **止损**：盘中即时触发，不需要等待收线
- 使用ATR（14周期）进行动态止损止盈管理

### 参数设置
- 分钟级别：26周期布林线，2倍标准差
- 日线级别：20周期布林线，2倍标准差

### 风险管理
- 硬止损：380元/手（分钟级别）
- 浮动止盈：盈利超过2个ATR后开始移动止损
- 移动止损：每盈利2个ATR，止损线推进1个ATR
- 开盘保护：早盘09:00-09:15、夜盘21:00-21:15不开仓（避免跳空）
- 收盘强平：14:58和22:58强制平仓（避免隔夜风险）

## 使用方法

### 基本用法

```bash
# 回测全部数据
python boll_backtest.py

# 指定时间范围
python boll_backtest.py --start 2020-01-01 --end 2023-12-31

# 设置初始资金
python boll_backtest.py --cash 200000

# 设置手续费率
python boll_backtest.py --commission 0.0002
```

### 参数说明

- `--start`: 回测开始日期，格式 YYYY-MM-DD
- `--end`: 回测结束日期，格式 YYYY-MM-DD
- `--cash`: 初始资金，默认 100000
- `--commission`: 手续费率，默认 0.0001 (万分之一)

### 示例

```bash
# 回测2022年全年数据
python boll_backtest.py --start 2022-01-01 --end 2022-12-31 --cash 100000

# 回测最近三年
python boll_backtest.py --start 2021-01-01 --end 2023-12-31

# 快速测试（只回测一个月）
python boll_backtest.py --start 2023-11-01 --end 2023-11-30
```

## 数据说明

- 数据文件：`OI9999.XZCE.csv`
- 品种：菜籽油主力连续合约
- 周期：1分钟K线
- 时间范围：2012年至今
- 字段：date, open, high, low, close, volume, money, open_interest, symbol

## 策略优化建议

1. **参数优化**
   - 调整布林线周期（默认26）
   - 调整标准差倍数（默认2.0）
   - 调整ATR周期（默认14）

2. **过滤条件**
   - 添加成交量过滤
   - 添加趋势过滤
   - 添加时间过滤（避开开盘收盘）

3. **风险管理**
   - 动态调整仓位
   - 添加最大持仓时间限制
   - 添加连续亏损后的冷静期

## 注意事项

1. 本程序仅供学习研究使用，不构成投资建议
2. 历史表现不代表未来收益
3. 实盘交易需考虑滑点、流动性等因素
4. 建议先进行小资金测试

## 常见问题

### Q: 如何查看更详细的交易记录？
A: 在策略类中设置 `printlog=True` 参数，会打印每笔交易的详细信息。

### Q: 如何保存回测结果？
A: 可以修改程序，将结果输出到CSV文件或数据库。

### Q: 如何进行参数优化？
A: 可以使用 Backtrader 的优化功能，或编写循环测试不同参数组合。
