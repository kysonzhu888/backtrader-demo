# 布林线策略 (Bollinger Bands Strategy)

## 策略概述

基于布林线的日内短线交易策略，专为菜籽油期货设计。

### 🆕 V2.2 最新优化（2025-08-12）
- **交易时间优化**: 精确判断菜籽油交易时间段，过滤非交易时间数据
- **历史数据下载**: 使用交易日期下载，避免非交易日数据为空
- **数据获取策略**: 根据当前时间智能调整数据获取范围（早盘获取12小时，其他获取8小时）
- **时间保护机制**: 完善开盘后15分钟和收盘前15分钟的保护期判断
- **数据充足性检查**: 确保有足够数据计算布林线（20周期）和ATR（14周期）指标

### 核心逻辑
- **开仓信号**: 突破上轨做多，突破下轨做空  
- **平仓信号**: 回撤到中轨平仓
- **风控机制**: 硬止损380元 + 浮动止盈
- **时间过滤**: 开盘后15分钟、收盘前15分钟不开仓

## 策略参数

### 技术指标
- **布林线**: 20周期，2倍标准差
- **ATR**: 14周期，用于浮动止盈

### 风控设置  
- **硬止损**: 380元（38个点）
- **浮动止盈**: 盈利超过2个ATR推保本，之后每盈利2个ATR推进1个ATR
- **止损保护**: 止损后30分钟内不开仓

### 数据配置
- **拉取频率**: 每6秒
- **分析周期**: 1分钟K线
- **预热期**: 30根K线

## 已知问题及解决方案

### 1. 时间显示问题
如果日志中显示的时间不正确（如显示凌晨1点而不是早上9点），这是时区问题。策略已做了优化处理。

### 2. 数据为空问题  
如果一直提示"K线数据不足"：
- 检查是否在交易时间运行
- 确认合约代码正确（如OI09.ZF）
- 等待几分钟让数据积累

### 3. download_history_data返回None
这是正常的，该函数没有返回值，只要没报错就说明下载成功。
