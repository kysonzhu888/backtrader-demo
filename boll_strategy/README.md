# 布林线策略 (Bollinger Bands Strategy)

## 📊 策略概述

基于布林线（Bollinger Bands）技术指标的日内短线交易策略，专为菜籽油期货（OI）设计。策略通过识别价格突破布林带上下轨的机会进行交易，结合ATR动态止盈和硬止损风控，实现稳健的日内交易。

### ⚡ 策略特点
- **标的选择**: 菜籽油期货（点值小，手续费低，适合短线）
- **交易频率**: 日内短线，不隔夜
- **风险控制**: 硬止损+浮动止盈双重保护
- **自动化程度**: 信号自动识别，微信实时播报

### 🆕 V2.2 最新优化（2025-08-12）
- **交易时间优化**: 精确判断菜籽油交易时间段，过滤非交易时间数据
- **历史数据下载**: 使用交易日期下载，避免非交易日数据为空
- **数据获取策略**: 根据当前时间智能调整数据获取范围（早盘获取12小时，其他获取8小时）
- **时间保护机制**: 完善开盘后15分钟和收盘前15分钟的保护期判断
- **数据充足性检查**: 确保有足够数据计算布林线（20周期）和ATR（14周期）指标
- **消息格式修复**: 修正微信播报换行符显示问题

## 📈 交易逻辑

### 开仓条件
- **做多**: 价格突破布林线上轨
- **做空**: 价格突破布林线下轨
- **时间限制**: 
  - 跳过开盘后15分钟（波动大）
  - 跳过收盘前15分钟（避免隔夜）
  - 止损后30分钟内不开仓（冷静期）

### 平仓条件
- **正常平仓**: 价格回归布林线中轨
- **硬止损**: 亏损达到380元（38点）
- **浮动止盈**: 
  - 盈利超过2个ATR后推保本
  - 之后每盈利2个ATR，止损线推进1个ATR

### 交易时间
菜籽油期货交易时段：
- **日盘**: 09:00-10:15, 10:30-11:30, 13:30-15:00
- **夜盘**: 21:00-23:00

## ⚙️ 策略参数

### 技术指标参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 布林线周期 | 20 | 计算均线和标准差的K线数量 |
| 布林线倍数 | 2.0 | 标准差倍数，决定通道宽度 |
| ATR周期 | 14 | 计算平均真实波幅的K线数量 |
| ATR倍数 | 2.0 | 用于浮动止盈的ATR倍数 |

### 风控参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 硬止损 | 380元 | 相当于38个点（菜籽油1点=10元） |
| 保本触发 | 2个ATR | 盈利达到此值后推保本 |
| 止盈推进 | 1个ATR | 每盈利2个ATR推进的幅度 |
| 止损冷静期 | 30分钟 | 止损后暂停开仓时间 |

### 系统配置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 数据拉取频率 | 6秒 | 用于实时监控止损 |
| K线周期 | 1分钟 | 信号判断的时间周期 |
| 数据预热期 | 30根K线 | 需要积累的最少K线数量 |
| 微信群名 | 动力波策略群 | 接收信号播报的群 |

## ⚠️ 风险提示

### 策略风险
- ⚠️ **震荡市场**: 布林线策略在震荡市中可能频繁止损
- ⚠️ **滑点风险**: 实盘交易存在滑点，影响实际收益
- ⚠️ **技术故障**: 网络中断、程序异常可能导致错过平仓

### 注意事项
- 📊 **充分回测**: 上线前进行至少3个月历史数据回测
- 🔧 **参数优化**: 根据市场状态动态调整参数
- 📅 **合约换月**: 关注主力合约切换时间（通常每月15日左右）
- 🌐 **网络稳定**: 使用稳定网络，建议配置断线重连
- 💰 **资金管理**: 单笔风险控制在总资金2%以内

## 🔧 参数调优指南

### 调整策略参数
修改 `boll_strategy.py` 中的 `BollStrategyConfig` 类：

```python
class BollStrategyConfig:
    # 布林线参数
    BOLL_PERIOD = 20      # 震荡市调小(15)，趋势市调大(25)
    BOLL_STD = 2.0        # 增加(2.5)减少交易，减小(1.5)增加交易
    
    # ATR参数
    ATR_PERIOD = 14      # 短期(10)更敏感，长期(20)更稳定
    
    # 风控参数  
    HARD_STOP_LOSS = 380  # 根据账户大小调整

```

### 参数优化建议
| 市场状态 | 布林周期 | 标准差 | ATR倍数 | 说明 |
|---------|---------|--------|---------|------|

| 震荡市 | 15 | 1.5 | 1.5 | 增加交易机会，快进快出 |

## 🐛 常见问题解决

### Q1: 时间显示不正确
**问题**: 日志显示凌晨1点而不是早上9点  
**解决**: 已在V2.2版本修复，确保使用最新代码

### Q2: K线数据不足
**问题**: 持续提示"K线数据不足，跳过信号检查"  
**解决**:
- 确认在交易时间运行（9:00-15:00, 21:00-23:00）
- 检查合约代码是否正确（如OI09.ZF）
- 等待20-30分钟让数据积累
- 检查QMT连接状态

### Q3: 微信消息显示\n
**问题**: 微信消息中出现`\n`而不是换行  
**解决**: 已在最新版本修复，使用单斜杠`\n`

### Q4: download_history_data返回None
**问题**: 日志显示"历史数据下载完成: OI09.ZF, 结果: None"  
**解答**: 这是正常的，该函数不返回值，没报错即成功

### Q5: 无法获取主力合约
**问题**: 提示"未找到菜籽油期货合约"  
**解决**:
- 确认QMT已登录
- 检查网络连接
- 确认有郑商所权限
